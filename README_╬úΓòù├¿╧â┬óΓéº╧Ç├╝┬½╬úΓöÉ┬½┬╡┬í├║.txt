憂井うめ公式HP・3カード整列＆スマホ表示対応版

修正内容
・HOMEのABOUT / CONTENTS / LINKSを均等な3列に変更。上下の大きな枠と左右端が揃います。
・中くらいの画面は2列、スマホは縦1列に自動切替。
・スマホで文字や画像が画面からはみ出しにくいよう調整。
・ABOUTページにもスマホ幅のはみ出し対策を追加。
・配信予定、文字編集、画像調整、既存のデザインとリンクは維持。

使い方
1. ZIPをすべて展開。
2. ご自身の images/ume.png と images/ume_about.png を images フォルダへ。
3. index.html を開く。
4. スマホ表示の確認：PCのChrome / EdgeでF12を押し、スマホ型アイコンを押す。

注意：画像自体は同梱していません。実機スマホでの表示は公開後に確認してください。
