文字の編集方法
1. index.html または about.html を開く
2. 上部の「文字を編集」を押す
3. 点線が付いた文字をクリックして入力
4. 「このページを保存」を押してダウンロードされた index.html / about.html を元のファイルに上書き
5. 公開時は text-editor.js を削除するか、HTML末尾の <script src="text-editor.js"></script> を削除してください。
注意: ブラウザの一時保存は端末ごとです。公開する場合は必ずHTMLを保存して上書きしてください。画像はご自身で images/ume.png と images/ume_about.png に配置してください。
