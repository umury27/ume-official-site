【お問い合わせフォームについて】
初期状態では送信できません。メールの宛先をこちらで勝手に決めないためです。
index.html の末尾にある const CONTACT_EMAIL = ''; を検索して、'' 内に公開用の問い合わせメールアドレスを設定してください。
設定するとフォームのボタンから利用者のメールアプリが開き、入力内容をメールの下書きに入れます。実際の送信は利用者がメールアプリで行います。
ブラウザだけで完結する直接送信フォームにするには別途フォームサービスやバックエンドが必要です。
