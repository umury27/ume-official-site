♡ SCHEDULE サムネイルの追加方法 ♡

1. images フォルダに自分の画像を入れる（例：valorant.png）
2. schedule.html を開く
3. 「配信予定を追加・編集する」を開く
4. 配信情報と「サムネイル画像」に images/valorant.png と入力
5. スライダーで大きさ・左右・上下を調整し、「予定を追加」を押す
6. 登録済みの予定を直すときは「編集」から変更する
7. 「スケジュールHTMLを保存」を押し、ダウンロードした schedule.html で元のファイルを置き換える

※画像自体はHTMLに埋め込まれません。公開するときも images フォルダ内の画像を一緒にアップロードしてください。
※ブラウザに保存した予定が優先される場合があります。表示が違うときは別ブラウザでも確認してください。
※HOME / ABOUT の文字編集や立ち絵調整はこれまでどおりです。
