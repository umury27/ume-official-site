YouTubeサムネイル自動表示版

1. schedule.htmlを開き、配信予定の追加・編集を開きます。
2. 配信URLにYouTubeの動画・ライブ配信URLを入力します。
3. 自動でサムネイルが表示されます。大きさ・左右・上下のスライダーで調整できます。
4. 予定を登録・更新して「スケジュールHTMLを保存」で公開用HTMLをダウンロードします。
5. ダウンロードしたschedule.htmlを元のファイルと差し替えます。

YouTube URLから動画IDを読み取り、YouTube公式画像サーバーの画像を表示します。APIキー不要。
非公開・未公開動画、サムネイル未生成、通信制限等の場合は表示できないことがあります。
手動画像パス（images/xxx.png）を指定した場合はそちらが優先されます。
既存の予定はブラウザのローカル保存に残っていれば引き継がれます。
