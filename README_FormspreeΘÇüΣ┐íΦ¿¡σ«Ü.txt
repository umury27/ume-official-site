お問い合わせフォームはFormspreeに接続済みです。
接続先: https://formspree.io/f/mrpejjnw

使い方:
1. このZIPを展開し、index.htmlを開いてください。
2. CONTACT欄にテスト用の名前・メールアドレス・メッセージを入力し送信してください。
3. 画面に完了メッセージが出ることと、Formspreeの管理画面に届いたことを確認してください。
4. 初回はFormspree側のメールアドレス確認が必要な場合があります。

注意:
・インターネット接続が必要です。
・file://でのブラウザ表示では送信が制限される場合があります。その場合はWebサーバー上でテストしてください。
・フォームURLは公開されるものです。
・ロゴや立ち絵の画像は同梱していません。imagesフォルダに自分で入れてください。
